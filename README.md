# Norway Kitchen — demo storefront (English, USD)
Dark luxe theme (charcoal / deep pine base, brass-champagne accents, Cormorant Garamond + Jost). Static site, no build step. Open index.html or serve: `python3 -m http.server 8000`.
- Data: assets/js/products.js (25 products, 7 categories, USD; free shipping over $75, else $7.99). Logic: assets/js/app.js. Styles: assets/css/style.css.
- Cart in localStorage; demo coupon NORDIC10. Checkout/contact/newsletter are demo forms: nothing is sent or charged.
- Brand name, reviews, contact details and policies are placeholders.
- Photos: Unsplash (free license, https://unsplash.com/license), downloaded locally. A few show third-party appliance brands; swap for your own product photos before launch.
